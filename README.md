
🚀 Cisco CCNA Mega Lab Portfolio
Welcome to my networking portfolio! This repository contains over 45 completed Cisco Packet Tracer labs that I have built to master the concepts required for the Cisco Certified Network Associate (CCNA) certification.

Each lab file (.pkt) represents a hands-on configuration challenge, ranging from basic device setup to complex enterprise network topologies.

📚 Skills & Technologies Covered
By completing these labs, I have gained practical experience in the following areas:

Layer 2 Technologies:

VLANs, VTP (Server/Client/Transparent), and 802.1Q Trunking

EtherChannels (LACP & PAgP)

Spanning Tree Protocol (STP, RSTP, PortFast, BPDU Guard)

Layer 3 Technologies:

IPv4 & IPv6 Addressing and Subnetting

Inter-VLAN Routing (Router-on-a-Stick & Layer 3 Switches)

Dynamic Routing Protocols: OSPF, EIGRP, and RIP

Static Routing and Default Routes

Network Services & Security:

DHCP, DNS, and NAT (Static, Dynamic, PAT)

Access Control Lists (Standard, Extended, Named)

Port Security, DHCP Snooping, and Dynamic ARP Inspection (DAI)

SSH Configuration and Device Hardening

WAN Technologies:

PPP, HDLC, and Frame Relay

GRE Tunnels and Site-to-Site VPNs (if applicable)
